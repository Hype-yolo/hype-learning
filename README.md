# Hype Learning

用 AI 边学边问、边讲边练。

**讲清一个小点 → 主动询问理解进度 → 出题并等待作答 → 根据回答调整 → 推进或补讲。**

## 安装

把下面这句话发给支持安装 Skill 的 Agent：

```text
帮我安装这个 Skill：https://github.com/Hype-yolo/hype-learning
```

安装后调用 `/hype-learning`，告诉它想学什么。例如：

```text
/hype-learning 我想学博弈论，零基础，请从生活中的例子开始。
```

也可以下载仓库 ZIP，通过支持上传技能的客户端导入。仓库根目录的 `SKILL.md` 是完整教学规则，无需其他 Skill 或脚本。

## 交互方式

- 一次讲一个能消化的小点，配具体例子。
- 主动问理解到了哪里，不只问“懂了吗”。
- 默认一次一道短题，不提前给答案，等待真实作答。
- 根据回答补讲、换例子、降低或提高难度。
- 可以随时要求提示、答案、跳过题目或更换主题。
